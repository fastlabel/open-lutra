Register device

Registers the device in AWS IoT, issues a certificate, and adds it to {{ group }}. The device gets only the certificate, never AWS credentials.
1
Choose a name and register. The certificate and private key are written to provisioned/ on this PC.
2
Download the registration bundle as a zip and copy it to the edge PC securely. The zip also contains setup.sh, cleanup.sh for starting over, and a README.md with instructions.
3
On the edge PC, unzip it and run sudo bash setup.sh <device name>. The version deployed to {{ group }} is delivered automatically.
4
Once it works, delete the private key from this PC. The record of when and to which device it was issued is kept.

Letters, digits and : _ -. The name must not already exist.
